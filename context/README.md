# context/

Reference material for Claude sessions working on BOONUS.

## Tracked in git

- `initial_context_for_claude.md`: the canonical project brief. Read it before writing
  anything about BOONUS. Versioned; see its change log.
- `sources/*.md`: public digests of the published source documents (citation, key
  facts with page references, quotable lines, differences from the brief's canonical
  values, relevance to BOONUS).
- `README.md`: this file.
